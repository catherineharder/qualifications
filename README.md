# My Qualifications Québec

A plain-language, bilingual (English and French) guide to the 8 official ways to get skills recognized in Québec, based on the Qualifications Québec diagram.

- 8 pathway pages with steps, times and official links
- Job list (permit required, optional certificate, not regulated) with search
- "Build my plan" questionnaire
- Glossary of acronyms and common questions

Everything is in one file: `index.html`. Open it in a browser, or publish it with GitHub Pages (Settings > Pages > Deploy from branch `main`, folder `/`).

This guide does not replace advice from the organizations listed. It is not affiliated with the Government of Québec or with Qualifications Québec.
